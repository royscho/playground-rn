Auth, Keychain & Route Guards

Mock email/password auth with Zustand, secure token in keychain, and protected navigation

feat(auth): Zustand auth store, keychain token storage, and protected routes

What was built

🔐

Keychain Token Storage

Auth token stored in iOS Keychain / Android Keystore only. MMKV holds non-sensitive user profile. Restored from keychain on rehydrate.

🏪

Zustand Auth Store

Persisted user profile in MMKV via partialize. Token excluded from persistence — lives in keychain. Named actions for DevTools.

🔄

401 Refresh Queue

API client queues in-flight requests on 401. Retries all after token refresh. On refresh failure: clears queue + calls logout.

🧭

Route Guard

RootNavigator reads token from store. Mounts AuthStack when null, AppDrawer when authenticated. Transition is instant — no loading screen.

⚡

useMutation Auth

Login and register use TanStack Query useMutation. Screens read isPending and error — no local loading state.

∞

Infinite Scroll Feed

useInfiniteQuery on FeedScreen. Paginated JSONPlaceholder posts with FlatList, end-reached trigger, and footer spinner.
