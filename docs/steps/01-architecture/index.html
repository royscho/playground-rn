Maps @/ to src/ across TypeScript, Babel, and Metro so imports never use relative ../../ paths.

Environment Config

Pre-commit Hooks

Husky v9 + lint-staged (ESLint + tsc on staged files) + commitlint enforcing the project's type(scope) format.

Path Alias — how it works

tsconfig
"@/*": ["src/*"]
→
IDE autocomplete + type checking
Babel
"@": "./src"
→
Runtime bundle resolution
Metro
extraNodeModules: { "@": "src/" }
→
Metro bundler resolver
Usage
import { Button } from '@/shared/components/Button'

Pre-commit Gate

git commit you type this
→
pre-commit npx lint-staged
→
eslint --fix staged .ts/.tsx
→
tsc --noEmit whole project
→
commit-msg commitlint
→
✓ committed if all pass
