Theme System & ScreenWrapper

Design tokens, dark/light mode with MMKV persistence, and a unified screen layout component

feat(theme): design tokens, dark/light mode store, and ScreenWrapper

What was set up

🎨

Design Tokens

Light + dark color palettes, spacing scale (xxs→xxl), and typography scale (h1→label) in shared/theme/

🌙

Theme Store

Zustand store with devtools + persist middleware. Survives app restarts via MMKV storage.

🪝

useAppTheme Hook

Single hook returns { colors, spacing, typography } for the active theme. No prop drilling — call anywhere.

📱

ScreenWrapper

Themed header with auto drawer/back detection, scrollable body, loading/error states, and sticky footer.

🗂

Nav Theme

React Navigation NavigationContainer receives a custom theme mapped from design tokens — drawer chrome switches with the toggle.
